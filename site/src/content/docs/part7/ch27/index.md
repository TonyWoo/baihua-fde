## 开场

陆远再回临江精工，是一年之后。王工在厂门口接他，第一句话是：我们队上个月自己把出库核对助手接上了，没等你们派人。

一年前，王工还是设备科的工程师，跟着陆远的小队学怎么把系统推上产线。一年后，他带的内部 FDE 队已经能自己接场景了。吃饭的时候厂长问了陆远一个问题，也是这一章的问题：你们这行，风头正盛，可现在 Agent 写代码比人还快，这岗位还能干几年？

## 白话讲解

回答这个问题，要先把 FDE 的活拆成两半，因为两半的命运完全不同。

![执行型与开路型分化图](/baihua-fde/images/ch27-two-paths.svg)
图：FDE 的活正在分化：执行型有标准答案，会被 Agent 吃掉大半；开路型没有标准答案，人更值钱。

一半叫执行型：步骤固定，输入输出清楚，做过一遍就能写成模板的活。按清单接数据源、写样板式的对接代码、生成接口文档、跑例行评估，这类活 Agent 一年比一年做得好，成本还低。硬撑着说这类活离不开人，是自欺欺人，它就是会被吃掉大半，剩下的只有审核和兜底。

另一半叫开路型：问题本身是含糊的，答案不在文档里，藏在一线工人的抱怨、互相矛盾的数据口径和部门之间的利益里。把真问题找出来，定下先做什么后做什么，谈拢各方，上线之后为结果负责。这类活没有标准答案，Agent 可以当很好的帮手，查资料、写草稿、试方案，但它不能替谁签字，也没人会因为它判断失误而找它谈话。责任落不到它头上，这类活就吃不掉。

还有一个信号值得看：Anthropic 花 1 亿美元办 Frontier Academy，训的不是自己的员工，是客户和伙伴的工程师，用 12 周驻留制带他们在自己公司里把一个项目做上线。厂商自己都判断，部署能力最终要长在客户身上。这就是内建化：标准活被内部队和 Agent 一起消化，厂商 FDE 退到只处理难题的位置。

![内建化时间线](/baihua-fde/images/ch27-inhouse-line.svg)
图：内建化的路线：厂商入驻、驻留带教、企业自建队、外援只评难题。

所以结论不是岗位消失，是岗位变窄变深：人少了，但留下的人要处理的，全是没有模板的问题。

对个人来说，这意味着一件很具体的事：趁早把自己的时间从执行型往开路型挪。接数据的模板写得再熟练，也只是在和工具比速度，这场比试人赢不了。值得下功夫的是另外几样：看懂一个行业的真实流程，听出客户嘴上说的和心里想的不是一回事，在信息不全的时候敢做判断、敢签字。这些能力长得慢，也正因为长得慢，才不容易被一夜之间复制走。

## 陆远的现场

这一年里临江精工的变化，王工如数家珍：内部队现在有五个人，出库核对助手是他们独立接的第二个场景，从访谈仓库班组到上线，用了五周。写代码这件事变化最大，样板代码和接口文档，队里先让 Agent 出初稿，人只改口径和边界条件，王工说，他现在花在访谈和验收上的时间，比花在代码上的多一倍。

陆远问他，那还需要我们吗？王工的回答很实在：日常场景不用了，明年想上的预测性维护，数据治理欠账太多，队里没人处理过，到时候还得请你们来评一次方案，带一段。

临走前，厂长请陆远给内部队讲一课。陆远没讲技术，只讲了入场那 45 天里犯过的三个错：差点按图纸流程做访谈、差点把样例数据的口径当真、差点在指标没定之前就动手写代码。王工在下面接了一句：这三个错，我们队今年全犯过一遍。屋里人都笑了。陆远说，这就对了，这些错不是靠工具躲得开的，是靠人一遍一遍踩出来、记下来、传下去的，这大概就是开路型活最实在的样子。

陆远回程的路上把这一年想了一遍，给自己列了张单子：他干的活里，接数据源的模板、部署清单、文档初稿，已经全交给 Agent 打头阵；找问题、拆目标、跟厂长谈取舍、为检出率签字，这四件事，一件都没少，反而更忙了。他说，这张单子就是这个岗位未来几年的样子：手上的活会被吃，脑子里的判断和肩上的责任不会。

## 翻车现场

翻车的故事正好是反面。一家企业听说 Agent 能写代码，把自己的部署队伍裁掉大半，新系统全部让工具自动生成、自动对接。上线那天很顺利，报表出得比原来还快。

问题一个月后才被发现：工具按字段名想当然地对接，把返修件也计进了合格数，报表里的合格率整整好看了一个月。没有人去车间核过这个口径，因为原来负责核口径的人，已经不在了。最后这家企业把人请回来，先花两周把数据口径逐项对清，再重新上线。省下的人力钱，赔进了返工和信誉里。

这件事的教训不在工具，工具按它理解的规则做事，没有错。错在把「动作可以自动」误读成「责任可以取消」。口径对不对，要有人去现场问、去核、去签字，这部分从来不在代码里。

## 要点回顾

- FDE 的活正在分化：执行型步骤固定、有标准答案，会被 Agent 吃掉大半；开路型问题含糊、要判断要负责，人更值钱。
- 判断一份活属于哪型，只问一句：这件事有没有标准答案。
- 内建化是大趋势：Anthropic 训客户的人、临江精工自建队跑起来，都是同一个方向，能力长回企业身上。
- 岗位的长期形态是变窄变深：厂商和内部队都只留处理难题的人，标准活由 Agent 加内部队消化。
- 被吃掉的是动作，不是责任。口径、取舍、签字，这三样交不出去。

## Kata

1. 把你现在的工作列成两栏：有标准答案的和没有标准答案的，各写五项。一年后你打算把时间往哪一栏挪？
2. 王工的队让 Agent 写样板代码，人盯口径和验收。给你的团队设计一条同样的分工线：哪一步起交给 Agent，哪一步必须人签字？
3. 全书案例到这里收尾。回头看第 8 章陆远入场时的临江精工，再看这一章，你觉得这家工厂真正买到的东西是什么？用三句话写下来。
