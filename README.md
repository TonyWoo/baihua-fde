# 白话 FDE

**写给开发者、企业和 AI 从业者的前线部署课** · 作者：Tony Wu

FDE（Forward Deployed Engineer，前线部署工程师）是 Palantir 发明、2026 年被微软、OpenAI、Anthropic、AWS 集体下注的岗位：把工程师派进客户现场，写生产代码，对业务结果负责。

这本书文字精简、多用图（每章 2–3 张蓝图风 SVG），把这个岗位一次说清：它是什么、为什么爆发、一个项目怎么跑完、企业内部怎么自己建队、个人怎么入行。

全书贯穿案例：工程师陆远被派到制造企业临江精工，把一个停在演示阶段的 AI 项目在 45 天里推上真实产线，后半程看着这家企业组起自己的内部 FDE 队。
